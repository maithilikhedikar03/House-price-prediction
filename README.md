# House-price-prediction
# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict house prices based on housing-related features. The project demonstrates the complete workflow of a basic Machine Learning regression problem, including data loading, exploration, visualization, model training, and evaluation.

## 🎯 Objective

The main objective of this project is to build a Machine Learning model that can learn from historical housing data and predict house prices.

## 📊 Dataset

The project uses the **California Housing dataset** available through Scikit-learn.

The dataset contains information about housing characteristics such as:

- Median income
- House age
- Average number of rooms
- Average number of bedrooms
- Population
- Average household size
- Geographic location

The target variable represents the median house value.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Google Colab

## 🔄 Project Workflow

1. Import required libraries
2. Load the California Housing dataset
3. Explore the dataset
4. Analyze features and target values
5. Visualize the data
6. Split the dataset into training and testing sets
7. Train the Machine Learning model
8. Make predictions
9. Evaluate the model

## 🤖 Machine Learning Model

The project uses **XGBoost Regressor** for house price prediction.

XGBoost is an ensemble Machine Learning algorithm based on decision trees and is commonly used for regression and classification tasks.

## 📈 Results

The model performance is evaluated using appropriate regression evaluation metrics.

The detailed results and visualizations are available in the Jupyter Notebook.
